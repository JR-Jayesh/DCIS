FAQ

Common questions

Is my resume data stored or sent to a server? +
No. CareerAI runs entirely in your browser. Your resume text, GitHub data, and profile information never leave your device. All NLP parsing and ML prediction happens client-side using JavaScript — your data is 100% private.
How accurate is the ML career prediction? +
The career scoring engine analyses your skill profile across major engineering disciplines. The more data you provide (resume + GitHub), the more useful the directional guidance becomes. It is designed as an informed second opinion from an AI career counsellor, not a deterministic oracle.
What file formats does resume analysis support? +
CareerAI supports TXT and Markdown (instant text extraction), PDF (real text extraction via PDF.js), PNG/JPG (image preview with OCR simulation), and PPT/PPTX (with guided conversion instructions). For best results, use PDF or TXT format.
Do I need a GitHub account to use CareerAI? +
No, GitHub is optional. You can run a complete AI analysis with just your resume and profile form. However, adding your GitHub username significantly improves the accuracy of skill detection and career match predictions by providing verified coding evidence.
Can I use CareerAI on mobile? +
Yes. CareerAI is fully responsive. On mobile you'll see a bottom tab bar for quick navigation, a swipe-open sidebar for full navigation, and a touch-optimised interface. The full AI analysis runs on mobile just as well as desktop.
How does the roadmap update over time? +
Your roadmap is saved locally in your browser. As you check off skills you've learned, the progress bar updates automatically. You can also regenerate the roadmap for a different career domain at any time using the domain selector buttons.
Project Abstract

What is this project?

📋 Abstract

The Dynamic Career Intelligence System is a final year B.Tech project that addresses the challenge of career decision-making for engineering graduates using Artificial Intelligence.

The system integrates Natural Language Processing (NLP) for resume skill extraction, Machine Learning algorithms for career suitability prediction, and GitHub API analysis for verifying real-world coding skills.

The result is a personalised, intelligent career intelligence dashboard — with skill gap analysis, phase-by-phase roadmaps, course recommendations, and live job market insights — all running entirely in the browser.

🎯 Problem Statement

Engineering graduates often lack structured guidance on which career path suits their skill set, leading to misaligned career decisions. This system solves that with data-driven AI analysis.

✅ Proposed Solution

An intelligent, multi-module web application that processes resume data and GitHub activity through NLP and ML pipelines to generate accurate, personalised career recommendations in real-time.

📐 Scope

33 engineering and technology domains modelled across civil, mechanical, electrical, electronics, chemical, aerospace, biomedical, data, software, security, product, design, and emerging fields; 75+ skills extracted by NLP; and 40+ curated course recommendations per profile.
